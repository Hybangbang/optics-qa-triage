# Public optics reference anchors

This file is an allowlist of public, vendor-neutral references. It is not a substitute for reading the source.

- ISO 10110 — Optics and photonics: Preparation of drawings for optical elements and systems.
- ISO 11145 — Optics and photonics: Vocabulary and symbols for lasers and laser-related equipment.
- MIL-PRF-13830B — Optical components: General specification governing the manufacture, assembly, and inspection of optical components (historical U.S. military specification; confirm current applicability).
- SPIE / Optica technical papers and tutorials — use only when the specific paper is known and relevant.
- Standard textbook treatments of geometrical optics, aberrations, Gaussian beam propagation, thin-film interference, and polarization.

The drafting prompt must never invent a page number, clause number, measured value, or vendor claim. If a claim cannot be tied to a public source, mark it as general practice to verify.
